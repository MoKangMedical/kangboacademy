# Release 1.0.7-rc6 - 2026-10-01

The website and backend were deployed successfully. Public HTTPS browser checks confirmed 65 core courses, 500 book-course cards across 19 categories, 500 live shop catalog rows, the local D3 knowledge graph, and no document overflow at 390px for the checked pages.

The local validation suite passed 226 tests. The production server runtime passed 79 backend tests, 11 isolated API checks, and extraction/identity checks for all 565 lesson bodies. The deployed code and pages have a fresh file backup and an integrity-checked SQLite snapshot; the protected learning dashboard was preserved.

WeChat Mini Program version 1.0.7 was uploaded successfully through the official developer tool. The upload receipt reports a 635435-byte package. Platform review and public Mini Program release are pending: the public platform currently requires administrator QR login. Simulator recovery and physical-device validation are also tracked separately.

This release fixes shared-catalog module compatibility, learning-state recovery, stale-login response handling, practice retry/idempotency, payment verification, local D3 loading, and mobile book-course navigation. New payments remain disabled. Authorized merchant goods, live book transactions, and final audio-opening verification remain pending.

The public source commit for the deployed release is dd71232fb7fb09ba69ee7d4e9db4c718790e414d. Historical September candidate reports describe earlier checks; this release note records the verified October status.

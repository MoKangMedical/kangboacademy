## 交付边界

本地候选交付包包含微信小程序源码、网站变更文件、后端迁移候选、共享课程目录、购书资料导入器及测试。它不是完整生产备份：565篇权威课程正文、在线音频、数据库和运行配置仍在服务器，未复制到源码包。当前没有合作商授权和商品ID，不宣称真实商品已接入或小程序已上线。

网站和小程序共用65门主干、500门书目、10阶段、19分类元数据；正文与权限由同一API提供。前端技术不同，3D探索等网站功能不是全部原生移植。不得更改锁定learn.html和19分类顺序。所有新课文、图片、讲解与原书版权的使用范围应在实际发布前审核。

首页套餐展示改为读取与小程序相同的/api/membership/plans，删除旧静态价格和未验证的导师/直播权益，不改变后端定价。网页支付闭环尚未核验，页面不创建订单、不收款；接口失败也不回退展示旧价格。

## 本地验收与构建

```sh
python3 tools/build_content_contract.py --check
node --test kangboacademy-miniapp/tests/*.test.js tests/*.test.js
python3 -B -m unittest discover -s tools -p 'test_*.py' -v
python3 -B -m unittest discover -s server_patch/backend/tests -v
python3 tools/build_delivery.py --output output/kangbo-delivery-NEW
python3 tools/verify_delivery.py output/kangbo-delivery-NEW
```

构建只接受新的输出目录，会重新运行测试；失败停止，不创建成功标记。包内包含各文件SHA256及测试记录，不含凭据、身份证、签名材料、生产数据库、开发者私有配置或历史报名附件。release-status.json单独记录外部门槛，不以自动化测试PASS代替上线许可。

验证环境使用Python 3.12，依赖记录在requirements-validation.txt。这不是生产环境锁定清单；上线前应读取当前生产依赖并验证兼容性。音频解码还需要ffmpeg/ffprobe。完整ASGI冒烟使用tools/smoke_backend.py和新的--report路径，在临时目录创建测试正文与SQLite；KANGBO_PROJECT_ROOT隔离数据，保持生产默认路径不变。测试内容不能当实际课程质量证据。

共享源修改后先重新构建，再检查生成物。--refresh是旧站目录首次导入工具，不是迁移后的同步方法。交付构建将共享清单JS及目录渲染JS的引用替换为内容哈希文件名，防止长期静态缓存维持旧目录。API必须不缓存用户权限；音频仍须按真实内容哈希单独发布，audioRevision为空不能视为已完成清理。

## 购书接入

当前线上只读检查为500条书名搜索、0条分成。推荐由真实书商成交，平台只承接课程及商品发现。具体步骤和空模板见partner-products.md。先匹配20至50本有库存的正确版本，获得书商授权与售后资料，使用--allow-partial校验，人工复核后形成合并候选；不得拿部分映射直接覆盖完整生产数据。

商家必须提供真实主体、授权引用、商品ID、准确跳转目标及售后责任；价格和分成须有依据。书名不是ISBN或版本证明。仅凭书名自动搜索不能自动上架。本站跳转、复制链接、点击、自报购买和本机缓存均不当作支付成功；商家订单回传未接入前，物流与退款在实际商家订单页处理。本站课程订阅与实体书交易分开，不把课程会员支付配置误当图书商家结算。
